# 综合旅游气象指数说明

## 1. 定位

综合旅游气象指数是在已有五项输出基础上构建的 0–100 分综合结果，用于表达茶卡盐湖某日的**综合旅游气象条件**。它不替代五项原始指数，也不包含降水、雷电、能见度、最大风速等旅游安全风险，因此不能解释为完整旅游安全结论。

五项原始指数仍应同时输出：UVP、着装保温需求 D、人体舒适度 C、温湿度指数 THI、风效指数 K。

## 2. 五项得分转换

### 2.1 人体舒适度

```text
S_C = C
```

当前 C 已为 0、25、50、75、100 的舒适度分值，直接作为综合子得分。

### 2.2 THI 与 K

THI、K 先按既有九级规则产生有方向分值 `score`，再转成便利度得分：

```text
S_THI = 100 - 12.5 × abs(THI_score)
S_K   = 100 - 12.5 × abs(K_score)
```

因此分值 0 对应 100 分；±2、±4、±6、±8 分别对应 75、50、25、0 分。

### 2.3 着装保温需求

```text
S_D = 100 - D
```

D 越高，代表全天出游所需的保温准备越多，因此在综合旅游气象条件中得分越低。D 本身仍按原始含义单独输出，不被解释为衣物实际厚度。

### 2.4 UVP：中等最佳

UVP 先按茶卡历史分位阈值划分为五档，再映射为：

| UVP 等级 | `S_UVP` |
|---|---:|
| 低暴露潜势 | 50 |
| 较低暴露潜势 | 75 |
| 中等暴露潜势 | 100 |
| 较高暴露潜势 | 75 |
| 高暴露潜势 | 50 |

设 UVP 等级序号为 1 至 5，且“中等”为 3：

```text
S_UVP = 100 - 25 × abs(level - 3)
```

该规则表达“适度日照条件最好、两端较弱”的旅游日照偏好；它不是标准 UVI 的健康风险分级。

## 3. 合成公式与重复计权处理

```text
TI = 0.35 × S_C
   + 0.15 × S_THI
   + 0.15 × S_K
   + 0.20 × S_D
   + 0.15 × S_UVP
```

权重和为 1。C 已由 THI、K 的最不利分值计算，D 也使用最低气温和 K；本方法按已确认口径保留这些重复影响，但将 THI、K 的直接权重降为各 0.15。

```text
C = min(S_THI, S_K)
```

因此 C 保留“最不利热条件”的核心作用；THI、K 的较低直接权重保留各自的独立表现；D、UVP 分别体现出行准备负担和日照条件。

## 4. 历史基准与等级

程序一对所有具备六项有效气象输入的历史日计算 TI，并以 20%、40%、60%、80% 分位数建立茶卡本地阈值。

当前 `baseline_tea_card_v2.xlsx` 的历史基准期为 1961-01-01 至 2026-07-11，有效样本数为 23,628 天，阈值为：

| 分位点 | TI 阈值 |
|---|---:|
| 20% | 21.349 |
| 40% | 36.745 |
| 60% | 58.937 |
| 80% | 69.944 |

对应等级为：极低、较低、中等、较高、高。

这些等级表示相对于茶卡历史气象日的综合位置，不表示游客满意度、健康风险或旅游安全概率。

## 5. 示例

对 `examples/forecast.json` 的输入，五项子得分为：

| 子得分 | 值 |
|---|---:|
| `S_C` | 75.00 |
| `S_THI` | 75.00 |
| `S_K` | 100.00 |
| `S_D` | 80.29 |
| `S_UVP` | 50.00 |

计算得到：

```text
TI = 76.06
等级 = 高
```

## 6. 版本边界

综合权重与 UVP 中等最佳规则是当前项目确认的第一版设计规则，不是由游客问卷、客流、订单或满意度数据估计得到的经验权重。若未来获得此类数据，应单独检验和更新权重、UVP 偏好曲线及综合等级解释，并升级方法版本和冻结基准文件。
